This repository stores my latest Machine Learning project, in which I used Logistic Regression to predict the outcome of the FIFA World Cup 2026 matches. As part of this project, I studied the data, identified and removed outlier values using the 1st and 99th percentile boundary clipping. 

As mentioned above, the project uses Logistic Regression to reach the desired outcome. Logistic Regression was chosen for the following reasons:

1. It comes in handy when it comes to predicting outcomes that can only have a maximum of 2 possibilites (for example, win or lose).
2. Coefficent weights allow tracking of feature impacts, such as ELO rank.
3. It serves as the required baseline before testing complex trees.
4. It is quickly trained and resists overfitting on structured data, and also outputs clear probability scores.

Challenges Faced and How I Overcame Them:
Initially, I faced some confusion in properly understanding how machine learning works. Therefore, I revisited the necessary topics using online sources to better understand machine learning. In addition, as a newcomer to machine learning, I was unaware of how to train models, so I used guidance from AI to develop an understanding of that as well, before proceeding with the project.
